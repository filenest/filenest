The `Filenest.Search` is used to filter all files by a query string.

<Callout>The component must be used as a child of `<Filenest.Root>`</Callout>

## Example Usage

```jsx
<Filenest.Search
  children={({ setSearch }) => (
    <input
      type="text"
      onChange={(e) => setSearch(e.target.value)}
      placeholder="Search files..."
    />
  )}
/>
```

<Callout>`setSearch` is debounced. For internal simplicity this is an uncontrolled input for now.</Callout>
