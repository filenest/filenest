The `Filenest.Uploader` is used to select files for upload.
It is using [`react-dropzone`](https://www.npmjs.com/package/react-dropzone) under the hood.

<Callout>The component must be used as a child of `<Filenest.Root>`</Callout>

## Example Usage

```jsx
<Filenest.Uploader
  children={({ rootProps, inputProps, isDragActive }) => (
    <div {...rootProps}>
      <input {...inputProps} />
      Drop files here or click to upload
    </div>
  )}
/>
```

<Callout>While you could use this component to track upload progress,
you should use the `<Filenest.Queue>` component instead, because it
offers more flexibility.</Callout>
