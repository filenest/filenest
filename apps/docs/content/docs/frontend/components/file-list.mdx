The `Filenest.FileList` is used to retrieve and display your files.

<Callout>The component must be used as a child of `<Filenest.Root>`</Callout>

## Example Usage

```jsx
<Filenest.FileList
  children={({ files, isLoading }) => {
    if (isLoading) {
      return <div>Loading...</div>
    }

    return (
      <div>
        {files.length === 0 && <div>No files found.</div>}
        {files.map((File, index) => (
          <File.Root
            key={index}
            children={({ file, rootProps, state }) => (
              <div>
                <div {...rootProps}>{file.name}</div>
                <File.Delete
                  children={({ trigger, isDeleting }) => (
                    <button
                      onClick={trigger}
                      disabled={isDeleting}
                    >
                      Delete
                    </button>
                  )}
                />
              </div>
            )}
          />
        ))}
      </div>
    )
  }}
/>
```
