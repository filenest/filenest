The `Filenest.FolderList` is used to retrieve and display your folders.

<Callout>Not every provider supports folders. However, using this component won't cause any problems.</Callout>

<Callout>The component must be used as a child of `<Filenest.Root>`</Callout>

## Example Usage

```jsx
<Filenest.FolderList
  children={({ folders, isLoading }) =>
    folders.map((Folder, index) => (
      <Folder.Root
        key={index}
        children={({ folder, rootProps }) => (
          <div {...rootProps}>
            <div>{folder.displayName || folder.key}</div>
            <Folder.Delete
              children={({ trigger, isDeleting }) => (
                <button
                  onClick={(e) => {
                    e.preventDefault()
                    e.stopPropagation()
                    trigger()
                  }}
                  disabled={isDeleting}
                >
                  Delete
                </button>
              )}
            />
          </div>
        )}
      />
    ))
  }
/>
```
