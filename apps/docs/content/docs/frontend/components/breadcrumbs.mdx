The `Filenest.Breadcrumbs` is used to display the current folder navigation levels.

<Callout>Not every provider supports folders. However, using this component won't cause any problems.</Callout>

<Callout>The component must be used as a child of `<Filenest.Root>`</Callout>

## Example Usage

```jsx
<Filenest.Breadcrumbs
  children={({ breadcrumbs }) => breadcrumbs.map((Breadcrumb, index) => (
    <Breadcrumb.Root
      key={index}
      children={({ folder, rootProps, isCurrent }) => (
        <div {...rootProps}>
          {folder.displayName || folder.key}
          {index !== breadcrumbs.length - 1 && " /"}
        </div>
      )}
    />
  ))}
/>
```
